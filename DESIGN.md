# Dirección visual de AI Redaction

Interfaz editorial para revisar documentos en español. Navegación lateral numerada, editor como área principal, observaciones con evidencia, indicadores acompañados de sus límites y acciones secundarias visibles.

Se consultó la habilidad UI/UX Pro Max con `document analysis dashboard`. Se aplican cuadrícula, espacio en blanco, contraste, jerarquía y estados visibles. Se adapta la propuesta visual al uso académico con azul marino, superficies claras, acento ocre y títulos de serif del sistema. No se carga tipografía externa. El patrón de landing propuesto por el buscador no se aplica a esta herramienta de trabajo.

Puntos de prueba: 375 y 1440 píxeles. Formularios con etiquetas, navegación de pestañas con flechas y Home/End, foco visible, enlace para saltar al contenido y mensajes de estado. Se respeta movimiento reducido. Los resultados y errores no dependen solo del color.
